# Mind_IA Privacy

Mind_IA applies data minimization and keeps sensitive data out of logs.

## Data rights

- Consent registration
- Data export
- Data deletion

## Stored data

- Profile data required for login
- Project and file metadata
- Audit and security logs with redaction

## Retention

- Authentication state is stored in memory for the local build
- Refresh tokens are rotated
- Deleted user data is purged from the in-memory stores used by the API
