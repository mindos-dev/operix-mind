# Mind_IA Compliance

Mind_IA is structured around concepts aligned with LGPD, ISO 27001, SOC 2 and OWASP Top 10.

## Implemented concepts

- Consent tracking
- User data export and deletion
- Audit and security logs
- Admin-only OAuth diagnostics export without secrets
- Input validation
- Rate limiting
- Redaction of sensitive fields
- Separation of auth, privacy, conversion and AI concerns

## Notes

- This repository is a product foundation, not a formal certification artifact
- Compliance evidence must be completed in deployment, process and operations
